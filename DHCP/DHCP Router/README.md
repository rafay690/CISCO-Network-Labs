# DHCP Router Lab

A Cisco Packet Tracer lab demonstrating dynamic IP address assignment using a Cisco router configured as a DHCP server.

## Concepts Practiced
- DHCP Configuration on Router
- Automatic IP Address Assignment
- Default Gateway Configuration
- Client DHCP Configuration
- Connectivity Verification

---

The network consists of a router, switch, and multiple PCs. The router provides DHCP services to clients.
