# Cisco Network Labs

A collection of Cisco Packet Tracer labs demonstrating networking fundamentals, device configuration, and routing concepts.

## Topics Covered

### Switch Based LAN
- Basic LAN topology
- MAC Address Table Verification
- Host Connectivity Testing

### Router LAN Network
- Router Interface Configuration
- IP Addressing
- Default Gateway Configuration
- ARP Table Verification
- Inter-Network Communication

### DHCP Server
- DHCP Service Configuration on a Server
- Automatic IP Address Assignment
- Client Connectivity Testing

### DHCP Router
- DHCP Configuration on a Cisco Router
- Dynamic IP Address Allocation
- Network Connectivity Verification

### Static IP Routing
- Multi-Router Network Configuration
- Static Route Configuration
- End-to-End Connectivity Testing

### Dynamic Routing (RIP)
- RIP Configuration
- Route Advertisement
- Dynamic Route Learning
- Network Connectivity Verification

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI
- Network Troubleshooting Commands

## Skills Demonstrated
- IP Addressing
- Switching
- Routing
- DHCP
- ARP
- Static Routing
- Dynamic Routing (RIP)
- Network Verification and Troubleshooting
