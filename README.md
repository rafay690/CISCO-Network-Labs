# Cisco Network Labs

A collection of Cisco Packet Tracer labs demonstrating networking fundamentals, device configuration, and routing concepts.

## Topics Covered

### Switch Based LAN
- Basic LAN topology
- MAC Address Table Verification
- Host Connectivity Testing

### Router LAN Network
- Router Interface Configuration
- IP Addressing
- Default Gateway Configuration
- ARP Table Verification
- Inter-Network Communication

### DHCP
#### DHCP Server
- DHCP Service Configuration on a Server
- Automatic IP Address Assignment

#### DHCP Router
- DHCP Configuration on a Cisco Router
- Dynamic IP Address Allocation

### Static IP Routing
- Static Route Configuration
- Multi-Router Communication
- Route Verification

### Dynamic Routing
- RIP Configuration
- Dynamic Route Learning
- Connectivity Verification

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI

## Skills Demonstrated
- IP Addressing
- Switching
- Routing
- DHCP
- ARP
- Static Routing
- Dynamic Routing (RIP)
- Network Troubleshooting
