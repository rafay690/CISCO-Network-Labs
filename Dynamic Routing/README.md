# Dynamic Routing (RIP) Lab

A Cisco Packet Tracer lab demonstrating dynamic routing using RIP (Routing Information Protocol) between multiple networks.

## Concepts Practiced
- Dynamic Routing
- RIP Configuration
- Router Interface Configuration
- IP Addressing
- Route Advertisement
- Connectivity Verification
