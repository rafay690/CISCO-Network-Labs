# Static Routing Lab

A Cisco Packet Tracer lab demonstrating communication between multiple networks using static routing across three routers.

## Concepts Practiced
- Static Routing
- Router Configuration
- IP Addressing
- Default Gateway Configuration
- Ping and Traceroute Verification
- Route Verification
